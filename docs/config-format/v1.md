# Fusen Config Format v1

This document describes the format of the Fusen settings file. Settings can be changed with `fusen config` (see the [command reference](../cli.md#22-fusen-config-key-value)) or in the settings of the Fusen window (see the [window reference](../gui.md#4-settings)).

## 1. File

- The file is located at `$XDG_CONFIG_HOME/fusen/settings.json`. If `XDG_CONFIG_HOME` is not set or is empty, it is `~/.config/fusen/settings.json`.
- The file is JSON, encoded in UTF-8.
- If the file does not exist or a key is omitted, the default value is used.

## 2. Format

### 2.1 Top level

```json
{
  "user": { ... },
  "prompt": { ... },
  "appearance": { ... },
  "kinds": { ... }
}
```

| Key | Type | Description |
|---|---|---|
| `user` | object | Information about you (see [2.2](#22-user)). |
| `prompt` | object | Settings for `fusen prompt` (see [2.3](#23-prompt)). |
| `appearance` | object | Appearance of the Fusen window (see [2.4](#24-appearance)). |
| `kinds` | object | Fusen kinds (see [2.5](#25-kinds)). |

All keys are optional.

### 2.2 user

| Key | Type | Description | Default |
|---|---|---|---|
| `name` | string | Your name, recorded as the author of your replies. | `"user"` |

### 2.3 prompt

| Key | Type | Description | Default |
|---|---|---|---|
| `language` | string | The language the AI replies in. Used for `{language}` in `fusen prompt`. | `"English"` |

### 2.4 appearance

| Key | Type | Description | Default |
|---|---|---|---|
| `theme` | string | `light` or `dark`. | `"light"` |

### 2.5 kinds

Defines fusen kinds, keyed by kind ID. IDs match `[a-z0-9_-]{1,32}`.

```json
"kinds": {
  "typo": {
    "label": "Typo",
    "description": "A typo or grammatical error. Fix it.",
    "color": "#ff6b6b"
  }
}
```

| Key | Type | Description | Default |
|---|---|---|---|
| `label` | string | Display name. | The kind ID with its first letter capitalized (`Typo` for `typo`) |
| `description` | string | Description of the kind. Used for `{kind}: {description}` in `fusen prompt`. | None |
| `color` | string | Highlight color, as `#rrggbb`. | `"#87ceeb"` (light blue) |

If `kinds` is missing or empty, Fusen writes the following built-in kinds to it. Only the kinds listed in `kinds` are used.

Kinds whose ID does not match `[a-z0-9_-]{1,32}` cannot be created with `fusen config` or in the settings of the Fusen window. If the settings file contains such kinds, Fusen removes them. A `color` that is not in the `#rrggbb` format is replaced with the default color (`#87ceeb`).

| ID | `label` | `description` | `color` |
|---|---|---|---|
| `comment` | `Comment` | `Feedback on the document. Consider it and update the document if appropriate.` | `#87ceeb` |
| `question` | `Question` | `A question about the document. Answer it, then clarify the document so the question no longer arises.` | `#87ceeb` |
| `suggestion` | `Suggestion` | `A suggested change to the document. Apply it, adapting it to the document if needed.` | `#87ceeb` |

### 2.6 Full example

```json
{
  "user": {
    "name": "tofu-12"
  },
  "prompt": {
    "language": "Japanese"
  },
  "appearance": {
    "theme": "dark"
  },
  "kinds": {
    "comment": {
      "label": "Comment",
      "description": "Feedback on the document. Consider it and update the document if appropriate."
    },
    "question": {
      "label": "Question",
      "description": "A question about the document. Answer it, then clarify the document so the question no longer arises.",
      "color": "#ffd166"
    },
    "suggestion": {
      "label": "Suggestion",
      "description": "A suggested change to the document. Apply it, adapting it to the document if needed.",
      "color": "#95d5b2"
    }
  }
}
```

## 3. Rules for writers

- Keys that are not recognized are preserved when the file is written back.
- The file is written to a temporary file first, then atomically replaced with a rename.
- The order of kinds in `kinds` is preserved. This order is the order in which kinds are listed in the Fusen window.
- If `kinds` is missing or empty, the built-in kinds are written to it.
- Kinds with an invalid ID are removed.
- A `color` that is not in the `#rrggbb` format is replaced with the default color.
